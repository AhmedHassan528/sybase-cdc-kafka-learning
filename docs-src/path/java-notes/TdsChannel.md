purpose
  RepAgent speaks TDS 5.0, Sybase's wire protocol, and TdsChannel is the lowest layer of the connector's side of that conversation. It cuts the byte stream of one socket into TDS packets: it reads packets and puts the pieces of one logical message back together, and it splits an outgoing response into packets of the agreed size. It knows nothing about what the messages mean.

class: TdsChannel
  Wraps one socket. One RepAgent connection gets one TdsChannel, and the channel is AutoCloseable so a session can close the socket with try-with-resources.

class: TdsChannel.Message
  The unit the rest of the connector works with: the packet type of a message and its payload bytes, after all its packets were joined.

method: TdsChannel.<init>(Socket)
  Takes the socket and keeps its input and output streams. Nothing is read or written yet.

method: TdsChannel.setPacketTrace(Consumer)
  Optional debugging hook: when a consumer is set, read() reports the header of every packet to it. It is off unless someone asks for it, so the normal path costs one null check.

method: TdsChannel.read()
  Reads one complete message. It loops over packets: read the 8-byte header, read the body, append it, and stop when the header's status byte says "last packet". It returns null when the connection ended cleanly between two messages, and throws EOFException if the stream stops in the middle of a header or a packet.

method: TdsChannel.sendResponse(byte[])
  Sends a response (packet type 0x04). The token bytes are split into chunks that fit the negotiated packet size, each chunk gets its own header, and the last one is marked with status 0x01. It is synchronized so that only one thread writes at a time and packets of two messages can never interleave on the socket.

method: TdsChannel.setPacketSize(int)
  Applies the packet size the client asked for at login. Values outside 512 to 65535 are ignored and the previous size stays (512 until a login sets it).

method: TdsChannel.remote()
  The remote address as text, used in log lines.

method: TdsChannel.close()
  Closes the socket, which also ends any read that is blocked on it.

method: TdsChannel.Message.<init>(int,byte[])
  The constructor of the record: it only stores the packet type and the payload.

method: TdsChannel.Message.toString()
  Generated by the compiler for the record. It prints the type and the payload, so a message appears in a log in a readable form.

method: TdsChannel.Message.hashCode()
  Generated by the compiler for the record. It is not used by the connector.

method: TdsChannel.Message.equals(Object)
  Generated by the compiler for the record. It compares the fields; the connector does not call it.

method: TdsChannel.Message.type()
  Accessor generated for the record component type: the packet type of the message.

method: TdsChannel.Message.payload()
  Accessor generated for the record component payload: the joined bytes of the message.

lines: 21-26
  The packet types of TDS that this connector knows. LOGIN (0x02) starts a session, NORMAL (0x0F) carries the token stream RepAgent sends after login, LANGUAGE (0x01) is an old-style command, ATTN (0x06) is an attention signal that the session answers, and RESPONSE (0x04) is what we send back. RPC (0x03) is declared but the session does not treat it specially: a packet type it does not handle gets a warning in the log and an empty DONE.

lines: 58-60
  The packet length is two bytes in big-endian order and includes the 8-byte header, so the body is length minus 8. A body shorter than that is a truncated packet and an error. The status byte's lowest bit (0x01) is what ends a message at line 63.

design
  TdsChannel does framing only. Keeping it free of any knowledge about logins or LTL means the two layers above it, the login parser and the LTL session, can be tested without a socket, and the wire format lives in one place.

fits
  TdsChannel is the bottom layer. LtlSession wraps every accepted socket in a TdsChannel, calls read() to get the next request from RepAgent and sendResponse() to answer it. The login record and the token builder in the same package build and parse what travels inside the packets.
