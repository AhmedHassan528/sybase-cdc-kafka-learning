purpose
  RepAgent sends a transaction in pieces, and only the commit makes it real. CommittedTransaction is what the buffer hands over once the commit has arrived: the transaction id, the position of the commit in the log, the commit time, the user who ran it and the row changes it contained, in the order they were logged. It is the unit that is published to Kafka and acknowledged as a whole.

class: CommittedTransaction
  A record: a plain immutable bundle of five fields (see the parameter list in the class comment). It has no behaviour of its own.

method: CommittedTransaction.<init>(String,byte[],String,String,List)
  The canonical constructor of the record; it stores the transaction id (hex), the commit position (the OQID of the commit record, which is the connector's position in the log), the commit time, the user and the list of changes.

method: CommittedTransaction.changes()
  Accessor generated for the record component changes: the insert, update and delete commands of the transaction, in log order.

method: CommittedTransaction.commitOqid()
  Accessor generated for the record component commitOqid. It is the position that is stored as the offset and reported to RepAgent once the whole transaction is in Kafka.

method: CommittedTransaction.commitTime()
  Accessor generated for the record component commitTime: the time RepAgent reported for the commit.

method: CommittedTransaction.equals(Object)
  Generated by the compiler for the record. The connector does not rely on it.

method: CommittedTransaction.hashCode()
  Generated by the compiler for the record. The connector does not rely on it.

method: CommittedTransaction.toString()
  Generated by the compiler for the record.

method: CommittedTransaction.tranId()
  Accessor generated for the record component tranId.

method: CommittedTransaction.user()
  Accessor generated for the record component user: the login that ran the transaction, taken from its begin command; it can be null if the begin was not seen.

design
  The commit position belongs to the whole transaction, not to a single row. That is why the offset the connector stores and the position it reports to RepAgent always lie on transaction boundaries, never in the middle of a transaction.

fits
  TransactionBuffer creates a CommittedTransaction when a commit arrives. ChangeEventMapper reads its fields to build the source part of each event, and SybaseCdcSourceTask publishes its changes and registers it with the acknowledgement tracker. Its changes are LtlCommand objects.
