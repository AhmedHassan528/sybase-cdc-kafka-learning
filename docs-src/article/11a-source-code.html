The source code and the JAR

Everything you build in the six increments ends in one file: a JAR that Kafka Connect loads as a plugin. This section shows where the Java code is, how it becomes that JAR, and what is inside. The code on this site is the reference solution of increment 6; it passes all 51 checkpoints (evidence/35). Each code page is the real file, copied when the site is built, not retyped, so it cannot drift from the repository.

Start with the code index: every file of the connector with a one-sentence summary, and the starter and solution files per increment.

Build the JAR

lab/env/mvn.sh solutions/06-package-and-run package -DskipTests

Maven runs in a container, so you only need Docker. I ran exactly this (evidence/52): Maven exited with code 0 after 15 seconds, with the dependency cache already warm. It wrote lab/solutions/06-package-and-run/target/cdc-lab-06-package-and-run-0.1.0.jar, 60,281 bytes, holding 31 class files: 7 in cdc, 8 in connect, 10 in ltl and 6 in tds. lab/experiments/build-jar.sh repeats the build and the checks below.

What is in the JAR, and what is not

The build file is pom.xml. It compiles for Java 17, and the maven-shade-plugin writes the single JAR during the package step. The Kafka Connect API (connect-api 3.8.0) and slf4j (slf4j-api 1.7.36) are marked provided: the Connect worker already has them, so they are compiled against and not packaged. The checks in evidence 52 confirm it: the JAR holds SybaseCdcSourceConnector.class and SybaseCdcSourceTask.class, and no class under org/apache/kafka/connect/, org/slf4j/ or org/junit/. In this build the JAR contains only our own 31 classes.

Increment 6's live check then copies your JAR into a temporary Connect worker, and the worker lists your connector class and runs it (evidence/35). That is how you know the JAR is packaged correctly.

Check yourself

1. The pom marks connect-api and slf4j-api as provided. What does that mean for the JAR, and how do you know?

They are used to compile the code but are not packaged, because the Connect worker supplies them. The check in evidence 52 found no classes under org/apache/kafka/connect/ or org/slf4j/ in the 31-class JAR.

2. Which class does Kafka Connect list as your connector, and how many tasks does it run?

SybaseCdcSourceConnector, with exactly one task, SybaseCdcSourceTask. RepAgent connects to one host and port per database.
