SybaseCdcSourceTask.java

sybase-cdc-connector/src/main/java/com/phoenix/cdc/sybase/connect/SybaseCdcSourceTask.java · 195 lines · every non-blank line is annotated (checked by gen-source.js)

Role: the heart of the connector. It starts the LTL listener, receives committed transactions, turns them into Kafka SourceRecords in poll(), and converts Kafka's acknowledgements into the truncation point returned to RepAgent. Read it together with diagrams 01, 05 and 17.

Threads: (1) the Connect task thread calls start, poll, stop; (2) the RepAgent session thread (created by LtlServer) calls the inner Listener; (3) the Kafka producer callback thread calls commitRecord. The BlockingQueue is the only hand-over between (2) and (1); AckTracker is synchronized for (2) and (3).

Delivery guarantee: at-least-once, verified by tests 4b, 6b and P5. Not exactly-once: duplicates after hard failures are expected and carry the same source.oqid.

Known limitation: nothing prevents two RepAgent sessions at once (the listener accepts every connection). RepAgent opens one session per database, and a second session was never observed with a single task, but the TransactionBuffer is not thread-safe. A follow-up should refuse a second concurrent session.

Lines 109–114

The offset rule (a fix made after the partial-publication analysis). Kafka Connect commits the offset of the newest record for which it and all earlier records are acknowledged. If every record carried its own transaction's commit OQID, a crash after only the first row of a 200,000-row transaction reached Kafka would store "this transaction is done", and the rest would be skipped as duplicates after restart. So the non-final records carry the previous transaction's position (partialOffset), and only the final record carries this transaction's commit OQID (doneOffset). Before the first-ever transaction completes, the safe offset is the empty string (read back as "no offset"). Evidence: test 6b: 53,822 of 200,000 records were in Kafka at the kill; the restarted task resumed from the previous transaction; all 200,000 rows arrived.
