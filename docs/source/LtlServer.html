LtlServer.java

sybase-cdc-connector/src/main/java/com/phoenix/cdc/sybase/ltl/LtlServer.java · 86 lines · every non-blank line is annotated (checked by gen-source.js)

Role: the TCP listener that RepAgent connects to, the network endpoint named CDC_RS in the ASE interfaces file. It accepts connections and starts one LtlSession thread per connection.

Security posture (as implemented): plain TCP, no TLS, no IP allow-list, no limit on concurrent connections. Authentication is the TDS login check only. In production, restrict who can reach the port with network controls (firewall, OpenShift NetworkPolicy); see the security chapter.

Lines 50–56

Accept loop. accept() blocks until RepAgent connects. TCP_NODELAY disables Nagle's algorithm, so small replies (DONE, truncation rows) are sent immediately; RepAgent waits for them, so delays here would slow replication. SO_KEEPALIVE lets the OS detect dead peers on idle connections.
