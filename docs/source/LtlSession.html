sybase-cdc-connector/src/main/java/com/phoenix/cdc/sybase/ltl/LtlSession.java · 251 lines · every non-blank line is annotated (checked by gen-source.js)

Role: one RepAgent connection, playing the part of a Replication Server. It reads TDS messages, answers the login and the three control commands (connect source, get maintenance user, get truncation) exactly as a Replication Server does, and hands LTL data to the listener. This is the class where most of the protocol discoveries live; every rule below was learned from a real failure (see the development history).

Protocol rules encoded here (all verified on ASE 16.0 SP02 PL02): (1) confirm the client's packet size in the login reply; (2) answer every LTL data message with exactly one DONE; (3) answer connect source with two result sets; (4) never acknowledge a message you could not parse: drop the connection instead.

Accepted login: LOGINACK (success, TDS 5.0, program "Replication Server" 16.0.0.0), the client's own capability token echoed back, and an ENVCHANGE confirming the requested packet size. Why ENVCHANGE matters: without it CT-Lib (RepAgent's client library) fell back to 512-byte packets and split RepAgent's 2,048-byte buffers so that an end-of-message flag landed mid-batch. The connector then answered twice; RepAgent read the extra DONE as its get truncation result (CT-Lib result type CS_CMD_SUCCEED = 4047) and aborted.

138    /** TDS 5.0 token stream: we expect a LANGUAGE token (0x21): u32 length, u8 status, text. */
139    private void tokenStream(byte[] p) throws IOException, InterruptedException {
140        if (trace) log.info("TDS message type=0x0f len={} head={}", p.length, hex(p, 8));
141        if (p.length >= 6 && (p[0] & 0xff) == 0x21) {
142            int len = order == ByteOrder.LITTLE_ENDIAN
143                ? (p[1] & 0xff) | (p[2] & 0xff) << 8 | (p[3] & 0xff) << 16 | (p[4] & 0xff) << 24
144                : (p[1] & 0xff) << 24 | (p[2] & 0xff) << 16 | (p[3] & 0xff) << 8 | (p[4] & 0xff);
145            int textLen = Math.min(len - 1, p.length - 6);
146            language(java.util.Arrays.copyOfRange(p, 6, 6 + textLen));
147            return;
148        }
Lines 138–148

TDS 5.0 token stream. Only the LANGUAGE token (0x21) is expected: 4-byte length in the client's byte order, 1 status byte, then the text. The length includes the status byte, hence len - 1.

233    static Charset javaCharset(String sybase) {
234        String s = sybase == null ? "" : sybase.trim().toLowerCase(Locale.ROOT);
235        return switch (s) {
236            case "utf8", "utf-8" -> StandardCharsets.UTF_8;
237            case "cp1256" -> Charset.forName("windows-1256");
238            case "cp1252" -> Charset.forName("windows-1252");
239            case "cp850" -> Charset.forName("IBM850");
240            case "iso_1", "" -> StandardCharsets.ISO_8859_1;
241            default -> {
242                try { yield Charset.forName(s); } catch (Exception e) { yield StandardCharsets.ISO_8859_1; }
243            }
244        };
245    }
