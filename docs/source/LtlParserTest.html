sybase-cdc-connector/src/test/java/com/phoenix/cdc/sybase/ltl/LtlParserTest.java · 124 lines · every non-blank line is annotated (checked by gen-source.js)

Role: the most important test class. It parses real LTL 760 messages captured from ASE 16.0 SP02 RepAgent (files in src/test/resources/ltl760/, saved by -Dltl.dump.dir). This turns the protocol discovery into a regression suite: any change that breaks decoding of real RepAgent traffic fails the build. When moving to ASE SP04, capture the same scenarios there, add the files and copy these tests.
