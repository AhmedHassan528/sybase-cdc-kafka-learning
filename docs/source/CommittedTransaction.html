CommittedTransaction.java

sybase-cdc-connector/src/main/java/com/phoenix/cdc/sybase/cdc/CommittedTransaction.java · 22 lines · every non-blank line is annotated (checked by gen-source.js)

Role: an immutable value that carries one finished (committed) database transaction from the TransactionBuffer to the Kafka task. It is the hand-over object between "we understood the log" and "we publish to Kafka".

Created by: TransactionBuffer.accept() when a COMMIT arrives. Used by: SybaseCdcSourceTask (queue, offsets) and ChangeEventMapper (event source block). Tests: TransactionBufferTest.

What: a Java record (Java 16+). One line declares an immutable class with five private final fields, a constructor taking all five, accessor methods named like the fields (tranId(), commitOqid(), …), and equals/hashCode/toString.

  • tranId: the ASE transaction id as hex text. Hex is used because the raw id is binary (e.g. 0000000000001c6d001a4d59...) and must be printable in the event's source.xid.
  • commitOqid: the origin queue ID of the COMMIT log record, as raw bytes. This is the transaction's position in the ASE log and becomes the Kafka Connect source offset and the RepAgent truncation answer. Bytes (not hex) because it is compared with Arrays.compareUnsigned.
  • commitTime: ISO-formatted origin_time of the commit (ASE server local time, no time zone).
  • user: the ASE login that ran the transaction, when RepAgent sent it (for / npw clause of begin transaction); may be null.
  • changes: the INSERT/UPDATE/DELETE commands in log order.

Why a record: the object crosses threads (RepAgent session thread → queue → Connect task thread). Immutable values are safe to share without locks. Caveat: byte[] and List are still mutable objects inside; the code never modifies them after creation, which is a convention, not a guarantee. If changed: adding a component requires updating the one constructor call in TransactionBuffer and the mapper. Alternative: a hand-written final class. Test: TransactionBufferTest asserts the changes list and order.
