Role: the class Kafka Connect instantiates when you create a connector. In Kafka Connect a Connector does not move data itself; it validates configuration and decides how many Tasks to run and with which configuration. The worker finds this class through META-INF/services/org.apache.kafka.connect.source.SourceConnector (Java's ServiceLoader mechanism) when it scans plugin.path.

API version: org.apache.kafka.connect.source.SourceConnector from connect-api 3.8.0. All methods overridden here exist with the same signatures since Kafka 2.x. Optional newer hooks (exactlyOnceSupport(), canDefineTransactionBoundaries(), alterOffsets()) are not implemented.
