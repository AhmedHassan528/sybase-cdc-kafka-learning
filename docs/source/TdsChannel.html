Role: TDS 5.0 packet framing on one socket. TDS (Tabular Data Stream) is the binary protocol Sybase clients and servers speak; RepAgent uses Sybase's Client-Library (CT-Lib), so the connector must speak TDS before it can see any LTL. A logical message is split into packets with 8-byte headers; this class reassembles incoming messages and splits outgoing ones.

Robustness finding: read() accumulates packets until the end-of-message flag with no upper size limit. A misbehaving or hostile client could make the worker allocate unbounded memory. Only RepAgent should be able to reach the port (network policy); a size cap is a recommended follow-up.
