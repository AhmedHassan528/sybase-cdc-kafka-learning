sybase-cdc-connector/src/main/java/com/phoenix/cdc/sybase/tds/TdsLogin.java · 73 lines · every non-blank line is annotated (checked by gen-source.js)

Role: reads the fields the connector needs from RepAgent's TDS 5.0 login record (packet type 0x02). The offsets follow the public TDS 5.0 login layout as implemented by the open-source FreeTDS project, and were confirmed against the real login packet captured from RepAgent (evidence ltl/capture-1-first-session.txt: user rs_user at offset 31, app "Replication Agent", server "CDC_RS", charset iso_1, packet size 2048).

Limits: name fields hold at most 30 bytes, so RepAgent passwords longer than 30 characters are untested. With net password encryption = true the password field is empty (RepAgent sends it later through an RSA challenge the connector does not implement).

56    /** The capability token is the tail of the packet: 0xE2, u16 length, body. Accept either byte order. */
57    private static byte[] findCapability(byte[] p) {
58        for (int i = 400; i < p.length - 3; i++) {
59            if ((p[i] & 0xff) != 0xE2) continue;
60            int be = ((p[i + 1] & 0xff) << 8) | (p[i + 2] & 0xff);
61            int le = ((p[i + 2] & 0xff) << 8) | (p[i + 1] & 0xff);
62            if (i + 3 + be == p.length || i + 3 + le == p.length) return Arrays.copyOfRange(p, i, p.length);
63        }
64        return null;
65    }
Lines 56–65

Find the capability token (0xE2) after offset 400 by checking that its 2-byte length (in either byte order) reaches exactly the end of the packet, so the layout does not have to be known precisely.
