LtlProbe.java

sybase-cdc-connector/src/main/java/com/phoenix/cdc/sybase/tools/LtlProbe.java · 86 lines · every non-blank line is annotated (checked by gen-source.js)

Role: a stand-alone diagnostic program (a main method, not part of Kafka Connect) that acts as a fake Replication Server and prints everything RepAgent sends. It was the tool used to discover the LTL 760 protocol and is the tool to use first against a new ASE version.

Never point a production RepAgent at the probe. It acknowledges the highest OQID it has seen, whether or not anything was delivered. ASE would then free log records that never reached Kafka, which is permanent data loss for the CDC pipeline. It also has built-in default credentials. Use it only against a test database.
