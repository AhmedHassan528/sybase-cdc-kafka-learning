sybase-cdc-connector/src/main/java/com/phoenix/cdc/sybase/tds/TdsTokens.java · 156 lines · every non-blank line is annotated (checked by gen-source.js)

Role: builds TDS 5.0 response token streams, the server side of the conversation. A TDS response is a sequence of tokens, each starting with a one-byte token id. The connector needs only seven of them, listed in the class comment. Methods return this so calls can be chained (tokens().rowFormat(...).row(...).done(...)).

Byte order: integers inside tokens are written in the byte order the client asked for at login (little-endian for RepAgent on x86_64). Only the packet header (in TdsChannel) is always big-endian.

81        Buf b = new Buf();

95    /** One row; values must match the row format: Integer for INT4, String for VARCHAR, byte[] for VARBINARY. */
96    public TdsTokens row(List<Column> cols, Object... values) {
97        out.write(0xD1);
98        Buf b = new Buf();
99        for (int i = 0; i < cols.size(); i++) {
100            Object v = values[i];
101            switch (cols.get(i).type()) {
102                case TYPE_INT4 -> b.u32((Integer) v);
103                case TYPE_VARCHAR -> { byte[] s = ((String) v).getBytes(charset); b.u8(s.length).raw(s); }
104                case TYPE_VARBINARY -> { byte[] s = (byte[]) v; b.u8(s.length).raw(s); }
105                default -> throw new IllegalArgumentException("type " + cols.get(i).type());
106            }
107        }
108        out.writeBytes(b.bytes());
109        return this;
110    }
Lines 95–110

ROW: one value per column in the declared format. The casts ((Integer) v, (String) v, (byte[]) v) throw ClassCastException on a programming error. Variable-length values are length-prefixed with one byte, so at most 255 bytes, enough for these answers.
