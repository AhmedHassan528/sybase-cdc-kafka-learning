LtlParser.java

sybase-cdc-connector/src/main/java/com/phoenix/cdc/sybase/ltl/LtlParser.java · 181 lines · every non-blank line is annotated (checked by gen-source.js)

Role: turns the token list of one LTL message into LtlCommand objects. It is a small recursive-descent parser: a cursor p walks through the tokens, and helper methods (atBare, next, skipSym) consume them according to the grammar in the class comment.

Robustness rule: anything not understood becomes Kind.OTHER and is skipped up to the next distribute; anything structurally broken throws IllegalArgumentException, which makes the session drop the connection without acknowledging (RepAgent re-sends after reconnecting). Tests: LtlParserTest (7 tests on 8 real captures).
