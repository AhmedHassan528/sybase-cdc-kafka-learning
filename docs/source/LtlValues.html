LtlValues.java

sybase-cdc-connector/src/main/java/com/phoenix/cdc/sybase/ltl/LtlValues.java · 99 lines · every non-blank line is annotated (checked by gen-source.js)

Role: converts each LTL value token into the Java value placed in the event (and then serialized to JSON by Kafka's JsonConverter). The table in the class comment is the verified type mapping; every row was captured from real ASE 16.0 SP02 traffic and is asserted in LtlParserTest.insertDecodesEveryDatatype.

Design decision: exact decimal types (numeric, decimal, money, smallmoney) become strings. A JSON number is usually read as a binary floating-point value, which cannot represent 0.10 exactly; for banking amounts a string is safer. Consumers must parse them with a decimal type (e.g. BigDecimal).

Known limits: the decimal scale is not preserved (ASE sends numeric(18,2) 100.50 as 100.5); unsigned bigint values above 263−1 fall back to a string; bigtime, unitext, text/image and user-defined types were not captured and are untested.
