Lines 20–32

A record with twelve components. Not every command uses every field; unused ones are null:

  • kind: what the command is (enum below).
  • originTime: ISO time from command tag 1; present on begin/commit only (row commands carry only tags 4 and 6; this was a test assumption that the real data corrected).
  • oqid: command tag 4, the 32-byte position. tranId: tag 6, the transaction id.
  • owner, table: e.g. dbo, payment (applied commands only).
  • before, after: column name → Java value (see LtlValues for the type mapping). Map<String,Object> because the values have different types.
  • keyColumns: primary-key column names, used as the Kafka message key.
  • tranName, user: from begin transaction (e.g. _ins, sa).
  • raw: the original command text, kept for debugging unknown commands.

If a component is added: update the single constructor call in LtlParser.command() and the test helper in TransactionBufferTest.
