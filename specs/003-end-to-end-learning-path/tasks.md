# Tasks: Sybase ASE CDC Connector, End-to-End Learning Path

**Input**: Design documents from `/specs/003-end-to-end-learning-path/`

**Prerequisites**: plan.md, spec.md, research.md, data-model.md, contracts/ (lesson-source, java-notes, env-values, path-site), quickstart.md

**Tests**: The spec defines measurable outcomes (SC-001 to SC-010), so the check scripts are part of the work. Each check script is written before the thing it checks and must fail first. Every check's output is saved with `lab/env/capture-evidence.sh` into `docs/evidence/` (Principle I). Anything not run is labelled "not run"; the certificate lesson is the only place with invented output, and it is labelled "Example, not run".

**Organization**: Grouped by user story. Paths are relative to the repository root. Output in `docs/site/path/` and `docs/evidence/path/` is generated by scripts and never edited by hand (Principle V). The connector source is not changed; the existing site pages are not changed (FR-001).

## Format: `[ID] [P?] [Story] Description`

- **[P]**: can run in parallel (different files, no dependency on an unfinished task)
- **[Story]**: US1 run the pipeline end to end, US2 understand the capture, US3 read the Java code, US4 navigation and progress
- Lessons use the ids of `plan.md`: 1.1 and 1.2 environment; 2.1 and 2.2 launch; 3.1 health, 3.2 certificate example; 4.1 and 4.2 database; 5.1 to 5.3 log and RepAgent; 6.1 and 6.2 replication; 7.0 to 7.20 Java; 8.1 to 8.3 build and Kafka; 9.1 to 9.4 demo. A lesson's text is finished only after its steps have been run for real and recorded.
