# Contract: Build-Along Increment

An "increment" is one numbered step of the build-along. It has nothing to do with the incremental (polling) mode of a JDBC
connector: this connector never runs a SELECT.

Each directory under `lab/increments/NN-name/` MUST contain:

| File | Purpose |
|------|---------|
| `README.md` | Goal, what is given, the checkpoints, the commands, the expected live output, what was not run |
| `starter/` | The learner's working copy: the previous solution plus the new code replaced by hinted TODOs. Generated by `make-starter.js` from the solution |
| `tests/` | JUnit tests shared by the starter and the solution: they fail on the starter and pass on the solution. They include the tests of all earlier increments |
| `verify.sh` | Runs the unit checkpoints (`starter` by default, or `solution`) through `lab/env/verify-increment.sh`; prints one PASS or FAIL line and, on FAIL, the first failing checkpoint |
| `verify-live.sh` | Live check against the real ASE (`starter` or `solution`): runs the learner's code in place of the connector (increments 1 to 5) or as a temporary Connect worker (increment 6), writes a real row, and prints PASS or FAIL with what is missing |
| `make-starter.js` | How the starter is generated from the solution |

And `lab/solutions/NN-name/` holds the reference solution (a Maven module that runs the same tests).

## Rules

- Increment N starts from solution N-1 (increment 1 starts from the TDS classes, which are given).
- Maven runs in a container pinned by digest (`lab/env/mvn.sh`); Docker is the only prerequisite for the build. Solutions compile
  for Java 17 and pass `mvn test`.
- The scripts are bash only (on Windows, Git Bash), like the experiments.
- Every starter must fail its unit checkpoints and its live check, and every solution must pass both
  (`lab/experiments/verify-all-increments.sh`, evidence 35).
- A live check must leave the finished connector `RUNNING` and delivering, whatever the outcome.
- The final solution is the finished connector `sybase-cdc-connector/`, except for the differences listed by
  `lab/experiments/compare-final-solution.sh` (evidence 38).
